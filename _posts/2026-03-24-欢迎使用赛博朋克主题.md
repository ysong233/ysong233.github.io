# 欢迎使用赛博朋克主题

这是你的第一篇博客文章！这个新主题为你提供了一个炫酷的赛博朋克风格。

## 功能展示

### Markdown写作
使用Markdown可以轻松编写文章:

- **粗体文本**
- *斜体文本*
- ~~删除线~~
- `代码片段`

### 代码高亮
支持多种编程语言的代码高亮:

```python
# Python示例
def hello_world():
    print("Hello World!")
    return "Success"
```

```javascript
// JavaScript示例
const message = "Hello Cyberpunk!";
console.log(message);
```

## 主题特性

### 1. 霓虹色彩
使用荧光绿和紫色的搭配，营造赛博朋克氛围。

### 2. 霓虹发光效果
文字和元素带有霓虹发光效果，增强视觉冲击。

### 3. 代码重点展示
代码块经过特别设计，突显技术感。

### 4. 响应式设计
完美适配各种设备，包括手机和平板。

## 如何写作

创建新文章很简单：

1. 在 `_posts` 目录下创建新文件
2. 命名格式: `YYYY-MM-DD-文章标题.md`
3. 添加Front Matter:
```yaml
---
title: "文章标题"
date: 2026-03-24
excerpt: "文章摘要"
categories: ["分类"]
tags: ["标签"]
---
```

4. 开始使用Markdown编写内容
